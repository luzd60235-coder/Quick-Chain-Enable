# OneL（一键桌面美化）

当前版本：1.0.4

让桌面在“美化模式”和“工作模式”之间一键换装，还能同时管理多组快捷键。

## 能做什么

- 按开关启动 Nexus、TranslucentTB 等软件
- 自动扫描开始菜单中的已安装应用（如 Steam、微信、VS Code、Chrome、VLC、WPS 等），无需手动填写路径
- 一键隐藏或显示桌面图标
- 一键隐藏或显示任务栏
- 自动隐藏任务栏：开启后任务栏收起，鼠标移到屏幕底部自动浮现；关闭则任务栏始终显示（与“隐藏任务栏”互斥，两者只能勾一个）
- 自定义全局快捷键，保存时直接替换旧快捷键
- 再次按下同一快捷键会退出该配置选中的应用，即使它们原本就已经在运行
- 左侧列表显示快捷键名称和组合键，右上角可新增多组配置
- 点击列表项即可编辑名称、组合键、软件和桌面效果
- 设置页支持开机启动、启动时最小化、保存提示等选项
- 点击窗口右上角关闭时会驻留通知区域，快捷键继续有效；右键托盘图标可真正退出
- 默认快捷键：`Ctrl + Alt + Shift + N`

## 使用方法

1. 双击 `OneL.exe`。
2. 左侧选择已有快捷键，或点击右上角“新增快捷键”。
3. 设置名称、组合键、软件和桌面效果，点击“保存快捷键”。
4. 按下对应快捷键，桌面进入美化模式；再次按下即可切回工作模式。
5. 点击右上角“设置”可配置开机启动、启动时最小化和保存提示。

保存成功后会立即显示“✓ 已保存并启用”，并重新注册全局快捷键；如果组合键已被占用，会明确显示占用原因和错误码，同时保留上一组可用快捷键，避免保存一次就“遥控器失灵”。

启动内容里的前三项是桌面效果（隐藏桌面图标、隐藏任务栏、自动隐藏任务栏），后面的“已安装应用”来自开始菜单扫描。软件会过滤卸载程序、说明文档和系统工具，只留下可以直接启动的应用；不同电脑会显示不同清单，正所谓“因机制宜，拒绝千篇一律”。

> 小提示：快捷键监听只在 OneL 运行时有效。把它最小化可以继续使用，关掉它就等于把遥控器也关了。

> 托盘模式：点击窗口关闭按钮只是把窗口收起来，不会退出程序。需要彻底退出时，右键通知区域的“OneL”图标，选择“退出程序”。

> 如果按 Clash Verge 的快捷键时提示“程序启动后立即退出”，先直接双击 `D:\Clash\clash-verge.exe` 检查它本身能否打开。启动器不会为了切换模式而强行关闭当前模式；Clash 修好后快捷键会自动继续使用。

## 文件说明

- `OneL.exe`：程序入口，可直接运行（内部组件 `一键桌面美化.dll` 等保持原名，请勿重命名）
- `AppLauncher.ps1`：界面与启动逻辑
- `OneL.ico`：程序图标（粉→青渐变闪电）
- TranslucentTB 不再随压缩包分发；如需使用，请单独安装。软件会自动查找已安装的 TranslucentTB。

配置默认保存到 `%LOCALAPPDATA%\OneClickBeautify\shortcuts.json`；如果系统拒绝访问，会自动回退到程序目录。

## 环境

- Windows 10/11（建议 Windows 10 1809 或更高版本）
- Nexus 需要安装在 `D:\nexus\Winstep\Nexus.exe`，如位置不同，请修改 `AppLauncher.ps1` 中的路径。
